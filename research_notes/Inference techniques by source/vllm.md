# vLLM inference optimization techniques (candidate plugin list for maxbox) — as of 2026-10-23

## Key question: What is the complete list of inference-optimization techniques implemented in vLLM (github.com/vllm-project/vllm) as of October 2026, one row per technique?

### Takeaway
As of v0.32.0 (released 2026-10-18) vLLM is a V1-only, Model-Runner-V2-default engine whose optimizations fall into ~15 swappable "seams": attention backend registry (31 standard + 26 MLA backend files), fused-MoE modular kernel (41 expert kernels x 6 prepare/finalize all2all backends), quantization config registry (~25 schemes over ~12 csrc kernel families), 9 torch.compile fusion passes with 4 CUDA-graph modes, 17 speculative proposers, 8+ KV-transfer connectors, and a hybrid KV-cache manager. The table below enumerates 221 candidate techniques; the repository tree, docs tree, release notes v0.29–v0.32 and the blog index were read directly, so most rows are grounded in a primary source, but per-row "claimed gain" numbers exist only where a release note or doc stated one.

**Verification legend used in the `status` column:** [T] = file/dir seen in the fetched GitHub tree listing; [R] = stated in a fetched release note (v0.29.0 2026-09-09, v0.30.0 2026-09-22, v0.31.0 2026-10-05, v0.32.0 2026-10-18); [D] = stated in a fetched docs page; [B] = title/summary seen in the fetched blog index (post body not read); [M] = from model memory, NOT re-verified against the Oct-2026 tree — treat as needing confirmation.

**Link bases:** TREE = https://github.com/vllm-project/vllm/tree/main/ ; REL = https://github.com/vllm-project/vllm/releases/tag/ ; DOCS = https://docs.vllm.ai/en/latest/ ; BLOG = https://vllm.ai/blog/
